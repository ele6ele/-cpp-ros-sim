# 用户手册 —— C++ 模拟 ROS 节点系统

## 1. 这是什么

一个用纯 C++（不依赖真实 ROS 的 API）模拟 ROS 核心通信机制的控制台程序：

| 类 | 角色 | 职责 |
| --- | --- | --- |
| `Node` | 员工手册 | 节点名 + 初始化/关闭两个必须实现的接口 |
| `Publisher` | 广播员 | 向指定话题发送消息 |
| `Subscriber` | 听众 | 接收订阅话题的消息并打印 |
| `Message` | 便条 | 内容 + 自动生成的时间戳（只读） |
| `RosCore` | 传达室（单例） | 登记节点、按话题转发消息、统一关闭 |
| `Logger` | 日志器（单例） | 分级日志，同时输出到控制台与 `logs/run.log` |

程序启动后**一次性跑完完整流程**，无需任何键盘输入。

## 2. 运行环境

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 x64 |
| 编译器 | Visual Studio 2022 及以上（"使用 C++ 的桌面开发"工作负载），本机为 MSVC 14.51 |
| 标准 | C++17（用到 `<filesystem>`） |
| 第三方库 | 无，纯标准库 + Windows 控制台 API |

## 4. 运行

```powershell
.\run.bat
```

或在 VS Code 里按 `F5`。运行后除了控制台输出，还会生成 **`logs\run.log`**（追加写入）。

## 6. 日志怎么读

**格式**：`[时间][级别][模块] 内容`

| 部分 | 含义 |
| --- | --- |
| 时间 | `YYYY-MM-DD HH:MM:SS`，日志产生时刻 |
| 级别 | `INFO` 正常流程 / `WARN` 非致命异常（被拦截的非法输入、无人订阅）/ `ERROR` 未预期异常 |
| 模块 | `Main` 演示流程、`Publisher` 发布者、`Subscriber` 订阅者、`RosCore` 核心 |

**日志同时写两份**：

| 位置 | 用途 |
| --- | --- |
| 控制台 | 现场演示、截图 |
| `logs\run.log` | 事后排查；追加写入，多次运行累积 |

程序启动时会调用 `Logger::setFile("logs/run.log")`；目录不存在会自动创建，打开失败则只输出控制台（并打印一行提示）。

## 7. 目录结构

| 路径 | 说明 |
| --- | --- |
| `include/` | `Node.h`、`Message.h`、`Publisher.h`、`Subscriber.h`、`RosCore.h`、`Logger.h`、`Exception.h` |
| `src/` | 对应实现 + `main.cpp`（演示入口） |
| `logs/` | 运行日志（`run.log`，已在 `.gitignore` 中忽略） |
| `docs/` | 需求、架构、路线图、用户手册、测试报告 |
| `build/` | 编译产物（已忽略） |
| `build.bat` / `run.bat` / `clean.bat` | 编译 / 编译并运行 / 清理 |

> ⚠️ `logs/run.log` 是**相对当前工作目录**生成的。用 `run.bat` 或在项目根目录运行，日志就在项目的 `logs/` 下；若在别处直接运行 exe，日志会落在那个目录。

## 8. 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| `cl` 不是内部或外部命令 | 正常现象：编译器未加入 PATH，请用 `build.bat` |
| 中文输出乱码 | 三件套缺一不可：源文件 UTF-8、编译 `/utf-8`、程序内 `SetConsoleOutputCP(CP_UTF8)` |
| 编译报 C4996（`localtime`） | 改用 `localtime_s(&tmValue, &t)` |
| 编译报 LNK1168 无法写入 exe | 上一次运行的程序没退出，关掉它的控制台窗口再编译 |
| 找不到 `logs\run.log` | 确认是在项目根目录（或通过 `run.bat`）运行；日志路径是相对路径 |
| 日志文件越来越大 | 追加写入所致，删掉 `logs\run.log` 即可 |

## 9. 已知限制

1. 节点是**同一进程内的对象**，不是独立进程（作业允许的简化）。
2. 消息通过**引用直接传递**，无序列化与网络传输。
3. **无交互式输入**：节点定义与消息内容硬编码在 `main.cpp`（与真实 ROS 用 launch/参数配置的思路一致）。
4. 不支持运行期动态增删节点（加分项 B-03 未实现）。
5. 无自定义消息类型（B-01）、无服务/客户端（B-02）。
