## 6. 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| `cl` 不是内部或外部命令 | 正常现象，用 `build.bat` 而不是直接敲 `cl` |
| 输出中文乱码 | 确认源文件 UTF-8、编译带 `/utf-8`、启动时 `SetConsoleOutputCP(CP_UTF8)` |
| 编译报 C4996（localtime） | 改用 `localtime_s` |
| IntelliSense 报找不到头文件 | `Ctrl+Shift+P` → `C/C++: Reset IntelliSense Database`，或检查 `.vscode/c_cpp_properties.json` 里的 MSVC 版本号 |
