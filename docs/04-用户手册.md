# 用户手册 —— C++ 模拟 ROS 节点系统

## 1. 这是什么

一个用纯 C++（不依赖真实 ROS 的 API）模拟 ROS 核心通信机制的控制台程序：

| 类 | 角色 | 职责 |
| --- | --- | --- |
| `Node` | 员工手册 | 节点名 + 初始化/关闭两个必须实现的接口 |
| `Publisher` | 广播员 | 向指定话题发送消息 |
| `Subscriber` | 听众 | 接收订阅话题的消息并打印 |
| `Message` | 便条 | 内容 + 自动生成的时间戳（只读） |
| `RosCore` | 传达室（单例） | 登记节点、按话题转发消息、统一关闭 |

程序启动后**一次性跑完完整流程**，无需任何键盘输入。

## 2. 运行环境

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 x64 |
| 编译器 | Visual Studio 2022 及以上（"使用 C++ 的桌面开发"工作负载），本机为 MSVC 14.51 |
| 标准 | C++17 |
| 第三方库 | 无，纯标准库 + Windows 控制台 API |

## 3. 编译

```powershell
.\build.bat
```

成功输出：

```
[build] compiling ...
main.cpp
Message.cpp
Node.cpp
Publisher.cpp
RosCore.cpp
Subscriber.cpp
正在生成代码...
[build] OK -> build\ros_sim.exe
```

`build.bat` 会自动用 `vswhere` 定位 Visual Studio 并加载 `vcvars64`，**不需要**把编译器加进 PATH。

## 4. 运行

```powershell
.\run.bat
```

或在 VS Code 里按 `F5`（会先自动编译，再启动调试）。

## 6. 输出怎么读

| 前缀 | 含义 |
| --- | --- |
| `[启动]` | 节点调用 `init()`，已向 `RosCore` 注册 |
| `[发布]` | 发布者构造了 `Message` 并交给核心转发 |
| `[接收]` | 订阅者 `onMessage()` 被调用，括号内是消息时间戳 |
| `[关闭]` | 节点调用 `shutdown()` |
| `[WARN]` | 非致命异常情况：话题无人订阅、消息内容为空 |
| `[OK]` | 非法输入被成功拦截（程序继续运行） |
| `[系统]` | 全局状态提示 |

## 7. 目录结构

| 路径 | 说明 |
| --- | --- |
| `include/` | 头文件：`Node.h`、`Message.h`、`Publisher.h`、`Subscriber.h`、`RosCore.h`、`Exception.h` |
| `src/` | 实现，`main.cpp` 为演示入口 |
| `docs/` | 需求、架构、路线图、用户手册、测试报告 |
| `build/` | 编译产物（已在 `.gitignore` 中忽略） |
| `tests/` | 预留的测试目录（当前测试内嵌在 `main.cpp` 与测试报告中） |
| `build.bat` / `run.bat` / `clean.bat` | 编译 / 编译并运行 / 清理 |

## 8. 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| `cl` 不是内部或外部命令 | 正常现象：编译器未加入 PATH，请用 `build.bat` |
| 中文输出乱码 | 需要三件套同时成立：源文件 UTF-8、编译带 `/utf-8`、程序内调用 `SetConsoleOutputCP(CP_UTF8)`（`main.cpp` 的 `initConsole()`） |
| 编译报 C4996（`localtime`） | 改用 `localtime_s(&tmValue, &t)` |
| 编译报 LNK1168 无法写入 exe | 上一次运行的程序没退出，先关闭它的控制台窗口再编译 |
| IntelliSense 报找不到头文件 | `Ctrl+Shift+P` → `C/C++: Reset IntelliSense Database` |
| 重新编译后运行还是旧结果 | 确认 `[build] OK` 出现；若报 LNK1168，说明旧进程仍在运行 |

## 9. 已知限制

1. 节点是**同一进程内的对象**，不是独立进程（作业要求模拟，允许简化）。
2. 消息通过**引用直接传递**，没有序列化与网络传输。
3. 程序**没有交互式输入**：节点定义、消息内容均硬编码在 `main.cpp`，与真实 ROS 用 launch/参数配置的思路一致。
4. 日志只输出到控制台，未持久化到文件（加分项 B-04 未实现）。
5. 不支持运行期动态增删节点（加分项 B-03 未实现）。
